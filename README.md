 # A.I.D.E.S.
## Artificial Intelligent Deadlock Elimination System

A futuristic Operating System project based on Banker’s Algorithm for deadlock detection and prevention.

## 🚀 Features
- Banker’s Algorithm
- Safe Sequence Detection
- Deadlock Detection
- Resource Allocation Visualization
- Process Scheduling
- CPU & Memory Monitoring
- Modern Dashboard UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Purpose
This project demonstrates intelligent operating system resource management and deadlock prevention using advanced visualization techniques.
